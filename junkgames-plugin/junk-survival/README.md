# JunkSurvival

めちゃくちゃなサバイバル。ブロックを壊すとランダムなアイテムと特殊アイテムが出て、ワールドボーダーは特殊アイテムで広がり、死ぬと縮みます。

[AzisabaNetwork/JunkSurvival](https://github.com/AzisabaNetwork/JunkSurvival)（3.2.1、Spigot 1.17、作者: 46kuri_。元は [LobbySurvival](https://github.com/AzisabaNetwork/LobbySurvival)）を Kotlin / Paper 26.3 に移植したものです。

## 機能

- 対象ワールド（`config.yml` の `survival-worlds`）で、不透明なブロックかガラスを壊すと、ランダムなアイテムが2〜10個出る。アイテムごとに一定の確率で特殊アイテムも出る
- 特殊アイテム
  - ワールドボーダー拡張（紙、左クリック）: ボーダー +10
  - どかーん（TNT）: 足元で威力10の爆発
  - びよーん（レッドストーントーチ）: 向いている方向に飛ぶ
  - みちづれ（鉄の剣）: オンラインのランダムなプレイヤーが対象ワールドにいれば倒す
  - ぱわー!!（金塊）: 強力なバフ
- 死ぬとボーダー -1、ジャイアントが出る。合計6回死ぬごとに、対象ワールドの全員の足元にランダムなモブ
- 何も特殊でないアイテムを持って空中を右クリックすると、ランダムなエンチャント（レベル1〜255）が付く
- ロビー（`lobby-world`）でエメラルド/ダイヤ/鉄/レッドストーンブロックを右クリックすると難易度を選べる（被ダメージを割る値が変わる）
- 一定時間ごと・ワールド移動時にバフ、エンチャントのコスト半分、スケルトンとクリーパーは湧かない、チャットの末尾に `///`

| コマンド | 権限 | 説明 |
|---|---|---|
| `/junksurvivalgive get <border\|bomb\|jump\|kill\|power>` | `junkSurvivalGive.permission.Admin` | 特殊アイテムを受け取る（旧版と同じ `1`〜`5` も使える） |

## 旧版からの変更点

挙動を変えたところ（主に、他のゲームに影響しないようにするため）:

| 項目 | 旧版 | 移行後 |
|---|---|---|
| 形式 | 普通のプラグイン | JunkGames SDK のゲーム（`JunkGame`）。`/junkgames` の選択画面に表示され、対象ワールドが JunkSurvival のワールドとして扱われる |
| コマンド | `plugin.yml` に宣言がなく、起動時にエラーになっていた | `plugin.yml` に宣言。権限ノードは旧版のまま |
| 特殊アイテムの判定 | 表示名の比較（金床で偽造できた） | アイテムのデータに印を付けて判定。旧版で作られたアイテムも表示名で引き続き使える |
| ジャイアントとランダムなモブ | 条件式の誤りで一度も出ていなかった | 対象ワールドで死んだときに出る |
| 対象ワールドの名前 | ソースに固定 | `config.yml` |
| 空中右クリックのランダムエンチャント、エンチャント半額、スケルトン・クリーパーの湧き停止、被ダメージ軽減、チャットの `///` | サーバー全体 | 対象ワールドだけ |
| 定期バフのお知らせ | 全員に送っていた | 対象ワールドにいる人だけ |
| 参加時・ワールド移動時の体力の再計算 | 体力を表示倍率で書き換えていた（体力が減る不具合） | 削除 |
| ランダムに出るアイテムの個数 | 1〜64個（スタック上限を超えることがあった） | 1〜スタック上限 |
